# 드론 임무 시뮬레이터 (Windows)

임무(출발지·경유지·날짜·시각·기체)를 입력하면 **그날의 기상 자료**를 가져와
임무 성공 여부를 판정하고, 구간별 소요시간·전력, **필요한 하드웨어 품목**을 보여주는
Windows 데스크톱 프로그램입니다. 비행제어 코드가 아닌 **임무 사전 평가 도구**입니다.

## 기능

- 지도 클릭으로 웨이포인트 입력 (고도·체공시간 편집, 마커 드래그)
- 기상 자료 자동 수집, 두 가지 소스
  - **기상청 단기예보**(공공데이터포털, 인증키 필요): 국내 5 km 격자, 발표일 기준 +3일, 초단기예보로 당일 보정
    (10 m 풍속·풍향, 기온, 강수확률·1시간 강수량, 하늘상태). 일출·일몰은 계산식으로 보강
  - **Open-Meteo**(키 불필요): 과거 날짜는 재분석 관측값, 최근·미래 날짜는 예보
    (고도별 풍속, 돌풍, 강수, 기온, 시정, 일출·일몰)
  - 기본값 `자동`: 인증키가 있으면 기상청, 없거나 실패(범위 밖·한도 초과 등)하면 Open-Meteo 로 폴백하고 상태줄에 사용 소스를 표시
- 바람을 반영한 구간별 지상속도·소요시간·배터리 소모 계산
- 항목별 판정: 풍속, 돌풍, 강수, 기온, 시정, 주·야간, 배터리, 이격거리, 고도, 경로 유지
- 몬테카를로 반복(기상·배터리 불확실성)으로 성공 확률과 실패 원인 분포
- 임무 조건에 따른 필요 하드웨어 목록 (규칙 기반, `dronesim/data/hardware_rules.json`)
- QGroundControl `.plan`, Mission Planner `.waypoints` 내보내기 → 1차 개발(SITL/실기체)에 그대로 사용
- 임무 저장/불러오기, 텍스트 보고서 저장
- **3D 비행 재생**: 지도 위 "3D 비행" 버튼으로 전환. 3D 지형(AWS Terrain Tiles)과 건물(OpenFreeMap) 위에
  경로를 비행 고도까지 세운 반투명 커튼과 드론 마커를 그리고, 시뮬레이션 결과의 구간별 시간·지상속도대로 재생
  (재생/일시정지, 1~30배속, 시간 탐색, 드론 추적 카메라, 고도·지상속도·배터리·바람 HUD, 지형 간격 5 m 미만 경고)

## 실행

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python run.py
```

Windows 11에는 WebView2 런타임이 내장되어 있어 별도 설치가 필요 없습니다.
지도 타일과 기상 자료는 인터넷 연결이 필요합니다.

브라우저에서만 화면을 확인하려면 개발 서버를 사용합니다.

```bash
.venv\Scripts\python -m dronesim.devserver 8765
```

## 기상청 API 인증키 설정

기상청 자료를 쓰려면 공공데이터포털 인증키가 필요합니다. 없으면 자동으로 Open-Meteo 를 사용합니다.

1. [공공데이터포털](https://www.data.go.kr) 가입 후 **"기상청_단기예보 ((구)_동네예보) 조회서비스"** 를 검색해 **활용신청**
   (일반적으로 즉시 승인, 개발계정 일 1,000건 한도).
2. 마이페이지 → 활용신청 현황에서 **일반 인증키**를 복사합니다. Encoding/Decoding 어느 쪽을 붙여도 됩니다
   (프로그램이 알아서 처리). 승인 직후에는 키가 반영되기까지 수십 분~1시간 걸릴 수 있습니다.
3. 키를 등록하는 방법은 둘 중 하나입니다.
   - **프로그램에서**: 왼쪽 패널 맨 아래 **설정 · 기상청 API 인증키** 를 펼쳐 키를 붙여 넣고 **저장**.
     **연결 확인**을 누르면 실제로 한 번 호출해 승인 여부를 알려 줍니다.
     저장 위치는 `%APPDATA%\DroneMissionSim\config.json` 입니다 (환경변수 `DRONESIM_CONFIG_DIR` 로 변경 가능).
   - **환경변수로**: `KMA_SERVICE_KEY` 를 설정합니다. 환경변수가 있으면 설정파일의 키보다 우선합니다.

     ```powershell
     [Environment]::SetEnvironmentVariable("KMA_SERVICE_KEY", "발급받은_키", "User")
     ```
4. 실행 카드의 **기상 소스** 드롭다운으로 `자동` / `기상청 단기예보` / `Open-Meteo` 를 고릅니다. 선택은 설정파일에 저장됩니다.
   결과의 상태줄과 기상 탭 하단에 실제로 사용한 소스(기상청 격자·발표시각, 또는 폴백 사유)가 표시됩니다.

기상청 자료의 제약: 국내 격자만 지원하고 날짜는 오늘 기준 +3일까지(과거는 보관 기간 내 며칠), 풍속은 10 m 한 레벨뿐이라
비행 고도 바람도 같은 값을 쓰며 **돌풍·시정 항목은 "자료 없음(참고)"** 으로 표시됩니다. 발표시각 이전 시각(예: 05시 발표 전 00~05시)은
가장 가까운 예보 시각 값으로 채우고 기상 탭 메모에 그 사실을 적습니다.

## 자동 업데이트

프로그램은 시작할 때 백그라운드로 공개 저장소 `jeegupapa/DG`의 최신 GitHub Release를 확인합니다.
설치된 프로그램은 인증 없이 조회하므로 저장소는 공개 상태여야 합니다. 조회 대상은 `config.json`의 `update_repo`로 바꿀 수 있습니다.

- 새 버전이 있으면 설치형은 `DroneMissionSim-Setup.exe`, 포터블(설치하지 않고 exe만 실행)은 `DroneMissionSim.exe`를
  내려받아 릴리스의 `SHA256SUMS.txt`로 검증합니다.
- 준비가 끝나면 왼쪽 상단에 배너가 뜹니다. **지금 적용**을 누르면 조용히 재설치한 뒤 다시 실행되고,
  **나중에**를 누르면 프로그램을 **종료할 때** 자동으로 적용됩니다(재실행은 하지 않음).
- 왼쪽 패널 아래 **업데이트** 카드에서 자동 적용을 끄거나 "지금 확인"을 누를 수 있습니다.
  설정은 `config.json`의 `auto_update`에 저장됩니다.
- 소스로 실행하는 개발 모드에서는 확인만 하고 적용하지 않습니다.
- 적용 과정의 기록은 `%TEMP%\DroneMissionSim-apply-update.log`에 남습니다. 업데이트가 적용되지 않았을 때 먼저 확인할 파일입니다.

**새 버전 배포 방법** (GitHub Actions가 빌드·업로드, 별도 준비 없음)

1. `dronesim/__init__.py`의 `__version__`을 올리고 커밋합니다.
2. 같은 번호로 태그를 붙여 push 합니다.

   ```bash
   git tag v0.2.3 && git push origin v0.2.3
   ```

3. `.github/workflows/release.yml`이 Windows 러너에서 테스트 → exe 빌드 → 설치파일 빌드 → 체크섬 생성 →
   이 저장소에 릴리스 생성·자산 업로드를 수행합니다.
   태그와 `__version__`이 다르면 실패합니다. 몇 분 뒤 설치된 프로그램들이 새 버전을 받기 시작합니다.

## 설치파일 만들기

exe 빌드 후 아래를 실행하면 Windows 내장 IExpress로 설치파일을 만듭니다. 별도 도구 설치가 필요 없습니다.

```powershell
.\installer\make_installer.ps1
```

- 산출물: `dist\DroneMissionSim-Setup.exe`
- 설치 위치: `%LOCALAPPDATA%\Programs\DroneMissionSim` (사용자 계정 범위, 관리자 권한 불필요)
- 시작 메뉴와 바탕화면에 "드론 임무 시뮬레이터" 바로가기 생성
- 설정 > 앱 > 설치된 앱(제어판 프로그램 제거)에 등록되어 거기서 제거 가능
- 조용한 설치: `DroneMissionSim-Setup.exe /Q`, 조용한 제거: 설치 폴더의 `uninstall.cmd /quiet`
- 코드 서명이 없으므로 처음 실행 시 SmartScreen 경고가 뜰 수 있습니다. "추가 정보 → 실행"으로 진행합니다.

설치 동작은 `installer/install.ps1`, 제거는 `installer/uninstall.ps1`에 있습니다.

## 구조

| 파일 | 역할 |
|---|---|
| `dronesim/main.py` | 데스크톱 창(pywebview) 진입점 |
| `dronesim/api.py` | 화면에서 호출하는 Python API (시뮬레이션, 파일 저장) |
| `dronesim/weather.py` | Open-Meteo 수집·파싱, 예보/과거 자동 선택 |
| `dronesim/weather_kma.py` | 기상청 단기예보·초단기예보 수집, 위경도→격자(LCC) 변환, 일출·일몰 계산 |
| `dronesim/weather_sources.py` | 기상 소스 선택(`auto`/`kma`/`open-meteo`)과 Open-Meteo 폴백 |
| `dronesim/config.py` | 사용자 설정파일(`%APPDATA%\DroneMissionSim\config.json`), 인증키 조회 |
| `dronesim/simulate.py` | 구간 모델, 항목별 판정, 몬테카를로, 종합 평가 |
| `dronesim/hardware.py` | 임무 조건 → 하드웨어 품목 규칙 엔진 |
| `dronesim/export.py` | `.plan` / `.waypoints` 생성 |
| `dronesim/data/profiles.json` | 기체 프로필 (성능·한계값). 기체 추가는 여기에 항목 추가 |
| `dronesim/data/hardware_rules.json` | 기본 품목과 조건별 추가 품목 |
| `dronesim/ui/` | 지도 화면 (Leaflet) |
| `dronesim/devserver.py` | 브라우저 확인용 개발 서버 |

## 판정 기준 요약

| 항목 | 주의 | 불가 |
|---|---|---|
| 풍속(비행 고도) | 한계의 70% 초과 | 기체 한계 초과 |
| 돌풍 | 한계의 80% 초과 | 기체 한계 초과 |
| 강수 | 강수확률 40% 이상, 방수 기체 강수 | 비방수 기체에 강수 |
| 기온 | 한계 5 °C 이내, 5 °C 미만 저온 | 운용 범위 밖 |
| 시정 | 기준의 1.5배 미만 | 기준 미달 |
| 주·야간 | 일출·일몰 30분 이내, 승인 보유 야간 | 승인·조명 없는 야간 |
| 배터리 | 가용 용량의 85% 초과 | 가용 용량 초과 |
| 이격거리 | 가시권 500 m 초과 | 텔레메트리 거리 초과 |
| 고도 | 150 m 초과(승인 필요) | 기체 최대 고도 초과 |
| 경로 유지 | 지상속도 순항의 50% 미만 | 맞바람·측풍이 순항속도 초과 |

가용 배터리 = 배터리 용량 × (1 − 예비 비율) × 기온 보정. 몬테카를로는 풍속 ±15%, 돌풍 ±12%,
기온 ±1.5 °C, 배터리 ±5%, 소비전력 ±7%, 강수확률 추첨을 섭동합니다.

## 한계

- 예보 해상도(수 km, 1시간)로 저고도 국지 바람은 추정값입니다. 결과는 확률로 해석해야 합니다.
- 기상청 단기예보는 10 m 풍속만 제공하므로 비행 고도 바람이 과소평가될 수 있고, 돌풍·시정 판정은 빠집니다.
- 공역·비행승인 판정은 참고용입니다. 드론원스톱에서 별도 확인이 필요합니다.
- 하드웨어 목록은 규칙 기반이며 기체 프로필과 규칙 테이블 품질에 좌우됩니다.
